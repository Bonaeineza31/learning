# Contact Us System

A simple backend API for handling contact form submissions, built during an internship project. Users can submit their contact information and messages, and admins can retrieve all submissions.

## Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB 

## Project Structure

```
backend/
├── models/
│   └── Contact.js      # Mongoose schema for contacts
├── server.js           # Express server and API routes
├── package.json
└── EXPLANATION.md      # Detailed code explanation
```
